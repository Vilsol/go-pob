---[Introduction]

go-pob is a port of Path of Building (PoB) to Go. It runs in a web browser, as a desktop app (Windows, macOS, Linux) and on phones.
go-pob's website is https://pob.gg, where the web version runs.
The calculations are ported from PoB's own code and checked against PoB's results build by build, so a build should show the same numbers in both.
The interface is its own: pages, menus and shortcuts differ from PoB's, and this help describes go-pob's.
Builds are PoB builds: go-pob opens PoB build codes, links and .xml files, and its exports open in PoB.

---[Contents]

---[Getting started]

The build list is the first screen. From there:
New build	Starts an empty build. It has no name until you save it (Ctrl+S asks for one).
Import build	Opens the Import / Export page.
Open a build	Double-click it, or select it and press Enter. Folders, search and sorting are at the top of the list.

Importing (Import / Export page, "Build import"):
Build code	A PoB export code.
Links	pobb.in, poe.ninja, pob.codes, Maxroll, Pastebin.com, PastebinP.com and poedb.tw. Links wrapped by YouTube or Google redirects work too.
Character JSON	A character's JSON (with "equipment" and "passives") imports its items, skills, tree and jewels.
Rentry.co	Not supported: paste the build code instead.
Choose "Import as a new build", "Import to this build" (asks first, and replaces everything in the current build) or "Import as a comparison" (opens it on the Compare page).

Character import: enter an account name and realm, press "Fetch characters", pick a league and a character, then import its passive tree and jewels, or its items and skills.
Other ways in: a passive tree link on the Tree page (Import Tree), a build code or link on the Party page, an ?import= link to the site, and on the desktop pob:// links and build files.

Where builds are stored:
Web	In this browser's own storage for the site. Other browsers and devices do not see them, and clearing the site's data deletes them.
Desktop	In a builds folder on disk, as .xml files. If Path of Building's Builds folder is found (including PoB's own "Build save path" setting, and Wine, Proton, Lutris and Bottles prefixes on Linux), go-pob uses it; otherwise it uses its own folder. File > Builds folder... picks another one, File > Default builds folder goes back.

Backups:
Export all builds	Settings > Data and storage > "Export .zip" saves every build as .xml files in one .zip. On the web this is the only copy outside the browser, so export regularly.
One build	Import / Export page: "Copy code", or "Share" to make a link on the chosen site.

---[Tree tab]

Click a node to allocate it and the path to it; click an allocated node to remove it and everything that depended on it. Hovering shows the path and the stat changes.
Right-click a node for its menu: tattoo or runegraft, socket a jewel, copy the node text, show it in the power report.
The bar under the tree has the search ("?" explains the syntax; the search is saved with the build), the Filter and Path choices, Reset Tree/Tattoos, Show Node Power, the Power report and the Timeless jewel search.
The tree selector manages several trees per build (Ctrl+M), imports and exports tree links, compares two trees and converts older tree versions.

---[Skills tab]

The left column lists the socket groups of the current skill set; the skill set selector and its Manage button are above it.
Click a group to edit it on the right: slot, gems, level, quality, enabled and "Include in Full DPS".
Ctrl+click a group enables or disables it; right-click makes it the main skill; Ctrl+right-click toggles it in Full DPS.
Gem options (default level and quality, sorting gems by DPS, legacy gems) are under the groups. Drag a group to reorder it.

---[Items tab]

Click a slot to edit its item; an empty slot offers to craft one. Hover a slot and press E to open the equipped item.
Paste an item copied in game (Ctrl+C there) or from PoB into the item text box. "Craft item..." and "New item" build one from scratch.
Drag items between the stash, the shared items and the slots. In the item lists, Ctrl+click equips (Ctrl+Shift+click uses the second slot), double-click opens the item as text, and the row menu has clone, copy, share with all builds and delete.
Item sets and the board/list layout are at the top. "Buy similar" builds a trade-site search from the item being edited.

---[Calcs tab]

Choose the skill to calculate (socket group, active skill, skill part, minion) at the top.
Hover a stat to preview its breakdown; click it to pin the breakdown.
"Mod Debug" lists the modifiers behind the calculation; "Manage Spectres..." edits the spectre library.

---[Config tab]

Sets the conditions the calculation assumes: enemy, charges, buffs and so on. Ctrl+F jumps to the search box.
Config sets have their own selector. "Reset to defaults" clears the options.

---[Party tab]

Adds support characters whose auras, curses and link skills apply to your build.
Paste a build code or link, pick a destination (or All), and press Import; tick Append to add to a section instead of replacing it. Clear empties the chosen destination.
The supporting build must be exported with "Export support" turned on (Import / Export page) for its auras and curses to come across.

---[Notes tab]

A rich-text editor for the build's notes, with headings, lists, task lists, quotes, code, links (Ctrl+K) and PoB's text colours.
The rich text is stored in the build; the PoB export flattens it to plain text with PoB colour codes. "Copy as PoB text" copies what PoB will get. Notes imported from PoB, or changed outside go-pob, show a banner with the choices.

---[Import tab]

Build sharing: "Copy code" copies the export code; "Share" uploads it to the chosen site and copies the link. "Export support" adds party data for the Party tab.
Build import and Character import are described under Getting started.

---[Compare tab]

Shows the current build (A) next to another build (B): a saved build, or one imported "as a comparison".
Views: Summary, Power report, Tree, Items, Skills, Calcs and Config. "Swap A and B" exchanges them; on Config, "Use B's value" copies a setting across.

---[Loadouts]

The Loadout selector in the top bar switches the tree, skill, item and config sets together. A loadout is formed when:
    1) all four sets have the same name (including colour codes), or
    2) all four sets end in the same identifier in braces, e.g. "Leveling Tree {1}". One set can join several loadouts: "Early Game {1,2}".
    3) a set type (other than the tree) with only one set joins every loadout.
"New Loadout" creates all four sets at once. "Sync" re-reads the loadouts.

F1	Open the hovered node on poewiki.net

Build list:

Lists, menus and fields:

---[Mouse and touch]

Passive tree with a mouse:
Drag	Pan
Wheel	Zoom (the speed is in Settings > Passive tree)
Ctrl+click / Ctrl+right-click	Zoom in / out at the pointer
Click	Allocate the node and its path, or remove an allocated node
Right-click	Node menu
The +, - and "fit" buttons zoom as well.

Passive tree on a phone:
Tap	Show the node's tooltip
Double tap	Allocate or remove the node. An Undo button appears for a few seconds.
Hold	Open the node menu
One finger / two fingers	Pan / pinch to zoom

Items:
Drag	Move an item onto a slot, into the stash or into the shared items. Drop onto the minion selector in the sidebar (Shift for the second slot) to give it to a minion.
On a phone, the first tap on an equipped item shows its tooltip; the second opens it.

Elsewhere:
Drag a socket group	Reorder groups (Skills)
Drag a build	Move it into a folder (build list)
Right-click or long-press Undo	Open the undo history (top bar); click an entry to go back to it
Shift+click	Select a range of Timeless jewel results

On a phone, five pages are in the bottom bar and the others (Notes, Party, Compare, Import/Export, Timeless) are under More, with Undo history, Loadout, Save as, Build issues, Settings and About. Tap the stats strip under the header to see all stats.

---[Desktop app]

The desktop app is the same app in its own window, with these differences:
Builds	Kept as .xml files in a builds folder (see Getting started), so PoB and go-pob can share one folder.
Opening files	File > Open build file... (Ctrl+O) opens a .xml build or a .txt build code. pob:// links and build files opened with go-pob from the system open in the running app.
Saving	"Export all builds" asks where to save the .zip.
Offline	The app is built in; game data and item images are downloaded once and kept on disk. Settings > Data and storage shows the size and clears it.
Updates	Ctrl+U (or Settings > "Check now") checks for a signed new version. Where go-pob can replace itself it downloads the update and restarts into it; the AppImage, .deb, .rpm and copies in a folder you cannot write to only name the new version and its release page. The Flathub and Nix builds are updated by Flathub and Nix.
Linux AppImage	Help > Add to applications menu adds a menu entry and the pob:// handler.

---[Offline and updates]

On the web, go-pob installs itself in the browser for offline use after the first visit. Offline, saved builds and calculations work; importing from links needs the network. A notice shows while you are offline.
The site checks for a new version every 30 minutes and when the tab becomes visible again. When one is ready, a notice offers "Reload" (unsaved changes are lost) and "Changes..." for what is new. Ctrl+U checks right away.
Opening the site with ?sw=off turns offline use off (and removes the offline copy); ?sw=on turns it back on.

---[FAQ]

Why does a number differ from Path of Building?
go-pob is checked against a fixed version of PoB, so a newer or older PoB can differ. Check that both use the same tree version, config and main skill. If they match and the number still differs, please report it with the build code.

Some mods say "(Not supported in PoB yet)". Is that go-pob?
That label comes from PoB: the mod is not handled by PoB's calculations either. Settings > Items can hide it.

Where are my builds?
On the web, in this browser's storage for the site; on the desktop, in the builds folder (see Getting started). Settings > Data and storage > "Export .zip" makes a backup.

Can I use my PoB builds folder?
On the desktop, yes: go-pob finds PoB's Builds folder by itself, or File > Builds folder... picks it. On the web, import builds by code or link.

Does clearing cached data delete my builds?
No. Settings > "Clear cached data" removes game data and item images, which download again. Clearing the site's data in the browser does delete web builds.

Why can a Rentry link not be imported?
Rentry only serves a paste with its owner's access code. Paste the build code instead.

Does it work offline?
Yes, after the first visit on the web, and always on the desktop once the game data is downloaded. Importing from links needs the network.

How do I report a bug?
Open an issue at https://github.com/Vilsol/go-pob/issues with the build code, what you expected and what you saw. Logs (top bar) has a button that copies the whole log with the app version and browser, to paste into the report.
